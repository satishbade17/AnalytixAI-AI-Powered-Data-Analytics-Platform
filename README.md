# AnalytixAI

An AI-powered Data Analytics Platform built with Python and Streamlit.

## Overview

AnalytixAI is a web application that allows users to upload datasets, preprocess data, perform exploratory data analysis (EDA), visualize insights, train machine learning models, and make predictions without writing code.

## Features

- Dataset Upload (CSV/Excel)
- Data Cleaning
- Missing Value Handling
- Feature Engineering
- Exploratory Data Analysis
- Interactive Charts
- Machine Learning Models
- Prediction System
- Download Reports
